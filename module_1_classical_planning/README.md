# Module 1 : Classical Planning

Run the RRT examples (either 2D or 3D) using
```bash
python3 rrt_*.py
```

In the 3D version, a sphere and a box represent the start and end point, respectively. 
The end point is connected to the closest node in the tree. The path is depicted in blue, 
while its "simplified" version is in green. The simplified path is generated by, starting from the end point, removing nodes toward the start point until a collision occurs, which sets a new point from which we start again. The RRT is depicted in gray, while the obstacles (either spheres or boxes) are colored in red.

Start and end points are sampled randomly in the free space, and obstacles have random size and poses.
Collisions are checked using ray-casting.
